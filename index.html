    P5 ROM testing model

    你不需要懂 ROM 格式来测 mapper：CI 里的 romfactory.mjs 会自动生成最小 iNES，给每个 PRG/CHR bank 填唯一字节，然后验证 bank switch、fixed bank、MMC1 5-bit serial register 和 mirroring。真实 ROM 只做 smoke test，不拿“看起来能玩”当 correctness。

    Battery-backed PRG-RAM 会按 ROM fingerprint 自动存进浏览器 localStorage；Save State 会保存 CPU/PPU/APU/Controller/Mapper/Bus/MasterClock 的可变状态并支持恢复。

    P5 precision boundary

    OAM DMA 已建模 513/514-cycle stall 与逐字节 bus read/write；DMC fetch 已有显式 4-cycle stall。APU 五个通道、frame sequencer、IRQ、非线性 mixer 和 48kHz PCM 已接入。当前 CPU 仍是 instruction executor，因此 DMC/OAM DMA 与某些 CPU read/write 的亚指令级总线冲突、$4017 写入 3/4-cycle delay、极端 IRQ race 还不是 transistor/cycle exact；这些现在会通过 timeline/dma trace 暴露，而不是藏在黑盒里。
